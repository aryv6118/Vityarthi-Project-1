SIMPLE BANK MANAGEMENT SYSTEM
1. Project Title:
Simple Bank Management System
2. Overview:
The Simple Bank Management System is a beginner-level, menu-driven Python application for performing basic banking operations. It demonstrates fundamental Python concepts such as functions, conditions, loops, lists, tuples, sets and dictionaries.
3. Features:
* Create a new bank account
* Deposit money
* Withdraw money
* Transfer money between accounts
* View account details
* View all accounts
* Calculate total, highest and average balance
* Demonstrate Python list, tuple, dictionary and set
4. Technologies / Tools Used:
* Programming Language: Python 3
* Tools: VS Code / PyCharm / IDLE / any Python IDE
* Concepts: Functions, loops, conditional statements and Python collections
* Libraries: No external libraries required
* Steps to Install & Run
* Install Python 3.
* Save the file as simple_bank_beginner.py.
* Open Terminal or Command Prompt.
* Go to the folder containing the file.
* Run:
python simple_bank_beginner.py
For systems using Python 3 separately:
python3 simple_bank_beginner.py
* Select the required option from the displayed menu.
5. Instructions for Testing:
Create Account
Enter the customer's name, age and opening balance.
Expected: A new account number is generated.
Deposit
Enter an existing account number and a positive amount.
Expected: The balance increases.
Withdraw
Enter an account number and withdrawal amount.
Expected: The amount is deducted if sufficient balance is available.
Transfer
Enter valid sender and receiver account numbers and an amount.
Expected: Money is transferred between the two accounts.
Statistics
Create multiple accounts and select Statistics.
Expected: Total, highest and average balance are displayed.
Collections
Select the Collections option.
Expected: List, tuple, dictionary and set examples are displayed.
* Note

* Conclusion
This project provides a simple practical application of Python programming concepts while implementing basic banking operations. It is intended for educational and beginner-level use.
